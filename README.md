# Work utils scripts
This is not the best code in the world. It is just a tribute. These lines of code are intended to provide utilities for making presentations, exploring new things and to act as notes to trigger memories. There is no quarantee that this will ever be useful or helpful for anyone, but feel free to try it out.

## How to use
Clone the repository or add it as a submodule in another repository. Then use the `manage.template` to create your `manage` file configured for your folder structure. See [manage.template](./manage.template) for instructions.

To see available commands run `./manage help`.
